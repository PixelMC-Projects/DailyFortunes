# 问津系列 · 原版像素风格试作

三件物品统一使用问津签筒二版已认可的风格：16× 像素密度、鲜明的蜜棕木材与青绿和朱红点缀、清晰的块状轮廓，以及双面的二维透空植物。

- 木纹、瓦缝等细节用连贯色块表现，不加入密集噪点或细叶脉。柔和来自颜色关系，不要求低饱和或整体发灰。
- 几何保留轮廓、屋顶、盖沿、铁箍与把手等有用的层次。抽屉贴近柜体，不为近乎看不见的内部结构建模。
- 相邻木板使用连续像素坐标，瓦片在屋脊两侧对应，顶部连接处不能漏空。纹理图集可以大于16×16；每方块长度对应16个纹理像素。
- 保留原始蓝本。这里的模型均为可编辑美术候选，尚未替换生产资源，未发布为模组发行版。

## Vanilla-style artwork studies

The set shares 16 texels per block, vivid honey wood, green and cinnabar accents, purposeful geometry, and double-sided cutout foliage. Fine grain and tile seams belong in connected pixel clusters rather than dense geometry. Neighboring surfaces keep aligned texture grids.

All three editable studies are separate from production assets. Open their `.bbmodel` files in Blockbench; textures are embedded. The combined preview uses one shared model scale. Integration and in-game performance verification remain separate work.
