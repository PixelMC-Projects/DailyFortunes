# 游戏用派生模型

此目录为 `art-source/` 蓝本的轻度有损派生副本。原始蓝本及原 FortuneArt 工程未修改，派生文件不可反向覆盖蓝本。

`*-report.json` 记录蓝本 SHA-256、前后面数、合面和隐藏面数量。比较性能看实际四边面数，而不是 Blockbench 元素个数；合面后的单面元素可能更多，但提交的面更少。

| 模型 | 原始四边面 | 当前四边面 |
| --- | ---: | ---: |
| 签筒 | 7,224 | 562 |
| 解签龛 | 5,604 | 1,183 |
| 藏签匣 | 3,870 | 610 |
| 合计 | 16,698 | 2,355 |

上一版共3,075面，本轮再减少720面（23.41%）；相对原始蓝本共减少85.90%。统计为三个模型的几何面数，不等同于整合包帧率提升。

签身刻痕、竹节小凸线、瓦面、铜环和嵌饰细节通过贴图保留；部分微小凸起厚度及隐藏侧面被舍弃，近距离观察会比蓝本平一些。主结构、瓦层轮廓、猫及主要叶片仍保留必要几何；细枝使用局部透明贴片。GUI 使用蓝本烘焙的两面图标，手持、掉落物和方块保持三维。

重新生成步骤见 `tools/README.md`。本轮客户端实测待用户完成，无新GitHub Release。
