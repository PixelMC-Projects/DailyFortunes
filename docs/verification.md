## 恢复数据

保留备份 JSON 和相邻的 `.sha256` 文件。需要恢复时，停止访问目标库的游戏/网页，创建独立空数据库并准备本地连接配置（`url`、`user`、`password`）。在包含本后端及 JDBC/Gson 依赖的 Manager 服务包目录运行：

```sh
java -cp service.jar cn.pixelmc.dailyfortunes.service.FortuneRestore backup.json connection.json RESTORE-EMPTY-DAILYFORTUNES
```

程序只接受尚无玩家、签历和操作历史的目标库；校验失败或目标非空会拒绝。恢复完成后核对数据，再将游戏/网页指向恢复库。不要把连接配置提交到 Git 或发送给客户端。单人内置数据库也可在完全关服后整体复制 `config/dailyfortunes/local-data` 作为离线备份。

内置 JSON 备份按容量和行数限制内存使用；数据超过限额时使用 MariaDB 原生备份，不截断历史。称号的异地备份不会自动覆盖新抽签库。
