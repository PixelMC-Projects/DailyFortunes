DailyFortunes Classic / 精细木作可选资源包

Minecraft 1.20.1, DailyFortunes 0.3.1 or compatible newer version.
此包保留此前优化过的精细签筒、解签龛、藏签匣，默认不启用。
将 ZIP 放入 resourcepacks，在“选项 → 资源包”手动移到已选列表即可。
移回可用列表会恢复模组自带的原版像素风。启用/停用均不改变签历或数据库。
签筒的转轴、晃动限制和悬浮签高度会随资源重载切换。
资源包只改变外观；方块碰撞范围统一由服务器默认模型决定。

Place the ZIP in resourcepacks and enable it manually in Options → Resource Packs.
Disabled by default. Includes the previously optimized detailed models, matching
icons, stick animation dimensions and floating-paper height. Disabling restores
the bundled vanilla-style models. No gameplay or storage changes. Server collision
shapes remain those of the default models for all players.
